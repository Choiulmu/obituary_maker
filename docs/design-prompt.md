# 부고장 서비스 화면 디자인 요청

## 서비스
어르신이 회원가입 없이 몇 가지 정보만 입력하면 온라인 부고장을 만들고,
그 링크를 카카오톡으로 공유하는 서비스입니다. 모바일 전용으로 봐 주세요.

## 사용자
- 60~80대. 스마트폰이 익숙하지 않습니다.
- 가족 상을 당한 직후, 경황이 없는 상태에서 씁니다.
- 도움 없이 혼자서 5분 안에 끝낼 수 있어야 합니다.

## 톤 & 무드
- 상황이 상황이니 절제된 톤. 밝은 컬러, 그라데이션, 이모지, 일러스트 금지.
- 무채색 + 아주 낮은 채도의 포인트 1색까지만.
- 슬픔을 과장하지 않되, 가볍거나 서비스 홍보처럼 보이지 않게.
- 종이 부고장의 격식을 화면으로 옮긴 느낌을 기준으로 삼아 주세요.

## 디자인할 화면 (5개)

1. **시작 화면** — 서비스 한 줄 설명 + [부고장 만들기] 버튼 하나.
2. **정보 입력 화면** — 아래 항목을 한 페이지 폼으로. 입력 오류 메시지 상태도 함께.
   - 필수: 고인 성함 / 별세일 / 장례식장 / 빈소 호실 / 발인일 / 상주 이름 / 상주 연락처
   - 선택: 장례식장 주소 / 조의금 계좌
3. **미리보기 화면** — 완성될 부고장을 그대로 보여주고, 아래에 [다시 고치기] [부고장 만들기] 두 버튼.
4. **완료 화면** — 발급된 링크 + [링크 복사] [카카오톡으로 보내기] 버튼, 그리고 [부고장 보기].
5. **부고장 화면 (가장 중요)** — 링크를 받은 조문객이 보는 페이지.
   - 구성: "부고" 표제 / 故 성함 / 별세 안내 문구 / 빈소(장례식장+호실) /
     장례식장 위치 / 발인 / 상주 / 연락처(전화 걸기) / 조의금 계좌 / [부고장 보내기]
   - 선택 항목(주소, 계좌)이 없을 때의 모습도 같이 보여 주세요.

## 지켜야 할 제약 (필수)
- 기준 화면 폭 375px, 모바일 우선. 데스크톱은 가운데 정렬 카드로 충분.
- 본문 최소 18px, 부고장 화면의 고인 성함은 크게.
- 버튼 높이 최소 56px, 화면 가로폭 가득. 한 화면에 주요 버튼은 하나.
- 명암비 4.5:1 이상. 회색 위 연회색 텍스트 금지.
- 라벨은 항상 보이게. placeholder만으로 라벨을 대신하지 마세요.
- 어려운 용어 금지. 에러 문구도 "이렇게 하시면 됩니다" 식의 쉬운 말로.

## 산출물 형식 (필수)
- **순수 HTML + CSS 한 벌**로 주세요. Thymeleaf 서버 렌더링 프로젝트에 그대로 얹습니다.
- 금지: React/Vue 등 프레임워크, Tailwind 등 빌드가 필요한 도구, CDN 링크,
  외부 이미지, 아이콘 라이브러리, JS 애니메이션 라이브러리.
- CSS는 별도 파일 하나(style.css)로, 화면별 클래스명을 의미 있게 지어 주세요.
- 폰트는 시스템 폰트(-apple-system, "Apple SD Gothic Neo", "Malgun Gothic")를 기본으로.
  웹폰트가 꼭 필요하면 이유와 함께 제안만 해 주세요.
- JS는 링크 복사/공유 정도에만. 그 외 동작은 HTML/CSS로 해결해 주세요.
- 값이 들어갈 자리는 실제 예시 텍스트(예: 홍길동, 2026년 8월 15일)로 채워 주세요.
